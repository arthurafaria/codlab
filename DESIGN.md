# Design

## Theme

Light product workspace for researchers working during daytime or evening on laptops and desktop monitors, often comparing instructions, images and spreadsheet-like results. The UI should feel calm, precise and serious without becoming sterile.

## Color

Use OKLCH tokens only. Strategy: restrained product palette with warm paper surfaces, ink-tinted text, a deep blue primary action and a green operational status color. Accent color should stay below 10% of the visible surface.

## Typography

Use one system sans stack. Fixed rem scale: compact labels, readable body, clear page titles. Avoid fluid typography. Keep prose around 65 to 75 characters where possible.

## Layout

Use an application shell with top-level task bars, split workspaces and table-like density. Avoid nested cards. Use panels only for discrete repeated or bounded tools. The coding screen should preserve a large image area and a predictable form area.

## Components

Buttons, inputs, selects and file controls share an 8px radius, strong focus ring and consistent hover states. Status indicators use badges, not colored side stripes. Progress appears as bars, counts and labeled states.

## Motion

Only state transitions, hover feedback and subtle reveals. 160 to 220ms ease-out. Respect reduced motion.
